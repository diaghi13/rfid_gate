## 🔧 **COMANDI QUICK START**

### 📥 **Setup Sviluppo**
```bash
# Clone e setup
git clone https://github.com/diaghi13/rfid_gate.git
cd rfid_gate

# Virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Dipendenze complete
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

### 🧪 **Testing Organizzato**
```bash

make test
```
